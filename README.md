# Budget Plan

Μια responsive web εφαρμογή διαχείρισης προσωπικού budget, η οποία επιτρέπει στον χρήστη να επιλέξει ένα πλάνο που επιθυμεί και να παρακολουθεί τις αγορές και τα έξοδά του.

# Περιγραφή

Ο χρήστης μπορεί να επιλέξει ανάμεσα σε τρία διαφορετικά πλάνα:
- Ετήσιο
- Μηνιαίο
- Ημερήσιο

Στη συνέχεια ορίζει το διαθέσιμο ποσό του budget και την ημερομηνία έναρξης του πλάνου. Μετά την επιλογή του πλάνου, η εφαρμογή μεταβαίνει δυναμικά στην αντίστοιχη σελίδα διαχείρισης του επιλεγμένου πλάνου.

Ο χρήστης μπορεί να καταγράφει τις αγορές ή τις υπηρεσίες που αγοράζει εισάγοντας τα στοιχεία:
- Ημερομηνία αγοράς αγαθού ή υπηρεσίας
- Όνομα αγαθού ή υπηρεσίας
- Ποσό αγοράς

Η εφαρμογή υπολογίζει αυτόματα το υπόλοιπο του διαθέσιμου budget.

Σε περίπτωση λανθασμένης καταχώρησης, ο χρήστης μπορεί να επεξεργαστεί ή να διαγράψει την καταχώρηση και το υπόλοιπό του υπολογίζεται ξανά.

# Βασικά Χαρακτηριστικά

- Επιλογή ετήσιου, μηνιαίου ή ημερήσιου πλάνου
- Ορισμός αρχικού διαθέσιμου budget και επιλογή ημερομηνίας έναρξης
- Καταχώρηση αγορών και υπηρεσιών
- Αυτόματος υπολογισμός υπολοίπου
- Επεξεργασία και διαγραφή καταχωρήσεων
- Αποθήκευση δεδομένων με localStorage
- Έλεγχος και validation των δεδομένων εισόδου
- Περιορισμοί στις τιμές και τις ημερομηνίες που μπορούν να καταχωρηθούν
- Error handling
- Event-driven λειτουργίες
- Responsive σχεδιασμός για διαφορετικά μεγέθη οθόνης
- Χρήση CSS Variables για τη διαχείριση των χρωμάτων και του styling
- Single Page Application (SPA)

# Τεχνολογίες

- HTML5
- CSS
- JavaScript
- Web Storage API (localStorage)
